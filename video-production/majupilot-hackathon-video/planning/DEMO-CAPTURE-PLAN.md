# MajuPilot 3:37 functional prototype capture plan

This is the locked Phase 1 capture choreography for the functional prototype portion of the
longer competition video. It is a 3:37 window inside a 9:40 working cut, not the full video
duration. Use the authentic public production app and fictional Case A only.

## Timing lock

- Full video working target: `9:40` (`17,400` frames at 30 fps), acceptable window `9:35–9:45`.
- Demo start: `3:15` (`5,850` frames).
- Demo end: `6:52` (`12,360` frames).
- Demo duration: `3:37` (`6,510` frames).
- Canvas: 1920×1080; capture and final render: 30 fps.
- Browser path: `https://majupilot-exabytes.vercel.app/` → fictional Case A → review → results → recommendations → scenarios → Blueprint → consultation.

## Operator choreography

1. Start at the public production URL in a clean, non-personal capture window. Confirm the
   visible wordmark is `MajuPilot` and the viewport shows the journey rail without clipping.
2. Use the Demo cases section to load only the fictional Kopi Kita Café Group case. Do not
   use a real business, real contact, or the portrait source.
3. Let the app finish each route transition before the next capture. Use deliberate holds on
   the exact values; avoid cursor trails over sensitive-looking fields.
4. On Scenarios, select Balanced Growth explicitly. Inspection focus alone is not a saved
   preference and does not unlock Blueprint handoff.
5. On Blueprint, allow the advisor review and secure-sync state to settle before showing the
   report. Capture a short proof of the 16-section index rather than a full scroll.
6. On Consultation, show the unchecked consent boundary and stop. No contact fields or
   urgency value should be filled for the recording.
7. Reset / close the capture session after the audit if the browser profile is not disposable.

## Do-not-capture list

- No personal portrait, passport / visa material, personal browser tabs, credentials, API keys,
  environment variables, private report links, raw prompts, or raw model reasoning.
- No real customer or consultation contact data.
- No consultation submission, webhook action, CRM action, or external message.
- No document upload or Document RAG demonstration.
- No claim that a planning range is a guarantee, quote, live vendor availability, or observed
  customer outcome.
