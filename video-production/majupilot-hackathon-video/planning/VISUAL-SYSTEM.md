# Stage 3 visual system

Canonical design truth: `../frame.md`.

## Concept

**Evidence Ledger Editorial** turns the production app's warm-paper, ink-navy, and teal language
into a film system. One continuous evidence path moves through six judged chapters: captured answers
become labelled evidence, deterministic calculations, scenario ranges, a source-linked Blueprint,
and finally an unchecked consent boundary. The device is specific to MajuPilot's promise of an
inspectable path; it is not generic AI decoration.

## Frame grammar

- 1920×1080, 30 fps; 120 px horizontal safe area.
- 12-column field, usually asymmetric 7/5 or 8/4.
- Chapter/index upper left; evidence receipt or timecode upper right.
- Key claim or live surface is the single focal element; qualifiers stay attached.
- Essential information stays above y=896 for captions.
- Light paper frames use 2–3 px borders and strong rules so compression does not erase structure.
- Live-capture placeholders are explicitly labelled `AUTHENTIC CAPTURE SLOT`; they are never fake
  product UI.

## Motion and seams reserved for Stage 5

- Primary seam: registry `directional-wipe`, leftward, 0.40 s.
- Quiet seam: registry `fade-through` or local blur-crossfade recipe, 0.50 s.
- Chapter reset: hand-authored vertical push from the HyperFrames transition catalog, 0.45 s.
- UI attention: registry `simulated-cursor`, `yt-feather-highlight`, and `ui-focus-zoom`.
- Data proof: registry `count-up` / `mk-progress-stat`; journey state: `state-chip-rail`;
  validation list: `mk-specs-list`.
- Bespoke architecture and provenance diagrams use HyperFrames `svg-path-draw`,
  `center-outward-expansion`, and `stat-bars-and-fills` because catalog searches returned no
  content-appropriate reusable item.

No registry item is installed in Stage 3 because installation would create composition code outside
the approved planning/design scope. Stage 5 should install selected items before any parallel scene
work.

## Accessibility and truth controls

- Text contrast is checked against `#FFFDF8` or `#082D3F`; small muted copy is never placed on pale
  teal/amber/coral without rechecking.
- Data uses tabular numerals and retains units, low/base/high labels, and negative signs.
- Fiction, provenance, planning assumption, historical baseline, and future-only states each receive
  an explicit label.
- Portrait use is limited to Frame 01; all other frames are faceless.
- The visual vocabulary never depicts Document RAG, a submitted consultation, CRM creation, vendor
  fulfilment, guaranteed ROI, or human acceptance.
