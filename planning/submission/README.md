# Stage 07 submission package

This directory is the self-contained handoff for the SME Growth Twin hackathon release candidate. It records what the software can prove, how to demonstrate it, and which human or external actions remain pending.

## Package map

- `DEMO-SCRIPT.md` — timed 8.5–9 minute narration.
- `SHOT-LIST-AND-CAPTIONS.md` — route/action/caption plan for a sound-off-readable video.
- `JUDGE-QA.md` — concise answers backed by product screens and tests.
- `ARCHITECTURE-AND-METHODOLOGY.md` — data flow, deterministic/AI boundary, fallback, originality, and limitations.
- `THIRD-PARTY-REGISTER.md` — dependency, provider, design-tool, source, and licence roles.
- `TEST-EVIDENCE.md` — exact commands, frozen A/B/C outputs, environment, and limitations.
- `DEPLOYMENT-RUNBOOK.md` — Vercel preview, verification, promotion, rollback, and failure recovery.
- `SUBMISSION-CHECKLIST.md` — automated complete versus manual pending gates.
- `MANUAL-VALIDATION-FORM.md` — blank five-user observation form; no results are invented.
- `RELEASE-MANIFEST.md` — manifest contract, checksums, versions, and external-state placeholders.

## Current truth

The application is a fictional-data hackathon prototype. Deterministic scoring, recommendations, scenarios, ROI, fallback advisors, Blueprint creation, and a process-local consultation record are implemented and verified locally and at <https://sme-growth-twin.vercel.app>. It has no authentication, tenant isolation, durable lead delivery, formal retention/deletion service, monitoring, audit log, CRM integration, or production compliance certification. No video upload, competition submission, human usability test, or official receipt is claimed by this package.
