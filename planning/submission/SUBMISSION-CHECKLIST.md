# Submission checklist

## Software-owned release gates

- [x] One schema-validated production fixture source for fictional A/B/C.
- [x] Scoped demo load/reset contract with persistent fictional label.
- [x] Exact deterministic golden assertions and fallback Blueprint completeness.
- [x] Advisor call/token/time budget and hashed-IP rate-limit implementation.
- [x] Security-header, secret-boundary, dependency-audit, and privacy checks prepared.
- [x] Hermetic axe/keyboard/responsive/clean-console/duration harness prepared.
- [x] Offline release, release-manifest, deployment, demo, Q&A, architecture, and third-party material prepared.
- [x] Final validation commands recorded as passing in `TEST-EVIDENCE.md`.
- [x] Main-task independent review and Stage 07 acceptance.
- [x] Reviewed Vercel artifact `READY` and deployed fallback journey verified.

## Manual/external gates — pending until real evidence exists

- [ ] Five human usability observations completed with the blank form.
- [ ] Exabytes/owner catalogue approval beyond official-source review.
- [ ] Judge Q&A rehearsal.
- [ ] Final build frozen 48 hours before the actual event.
- [ ] Final narrated 6–10 minute video rendered.
- [ ] Video uploaded to YouTube.
- [ ] YouTube visibility verified while signed out.
- [ ] Competition form fields reviewed by a human.
- [ ] Competition entry submitted.
- [ ] Official receipt and exact submitted build/video/report archived.

Unchecked items must not be described as complete in README, video, deployment metadata, or the competition form.
